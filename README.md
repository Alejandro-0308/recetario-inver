# Recetas Inver

Aplicación web desarrollada con React JS que permite visualizar recetas mediante un carrusel y completar un formulario para compartir nuevas recetas.

## Funcionalidades

* Visualización de recetas con botones para avanzar y retroceder.
* Formulario para compartir recetas.
* Validación de campos obligatorios.
* Opción para incluir ingredientes y preparación.
* Mensaje de confirmación al enviar el formulario.
* Navegación entre las páginas de recetas y de envío.

## Tecnologías utilizadas

* React JS
* JavaScript
* HTML / JSX
* CSS
* React Router DOM
* Create React App

## Instalación y ejecución

1. Descargar o clonar este repositorio.

2. Abrir una terminal en la carpeta del proyecto.

3. Instalar las dependencias:

   ```bash
   npm install
   ```

4. Iniciar la aplicación:

   ```bash
   npm start
   ```

La aplicación se abrirá en el navegador, normalmente en `http://localhost:3000`.
